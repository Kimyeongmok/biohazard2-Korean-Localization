*BIOHAZARD 2 (Steam) 한글 패치*
=============================
버전: v1.0.6 (2026-10-02)

**대상**
- Steam판 BIOHAZARD 2 (앱 4249110)의 일본어판 실행 파일(클레어편, 레온편)
- 게임 파일은 들어 있지 않습니다. 설치 프로그램이 가지고 계신 원본 파일을 확인한 뒤 바뀐 부분만 고쳐 씁니다.

**설치**
1. 게임과 런처를 끕니다.
2. BIOHAZARD2_Korean_Patch.exe 를 실행하고 1(설치)을 고릅니다.
   - 게임 폴더는 자동으로 찾습니다. 못 찾으면 경로를 물어봅니다.
     (설치 파일을 게임 폴더에 넣고 실행해도 됩니다.)
3. Steam에서 게임을 실행하고, 런처의 Language(언어) 목록에서 한국어를 고른 뒤
   클레어편/레온편을 시작합니다.

**새 버전으로 업데이트**
- 이전 버전을 지우지 않고 새 BIOHAZARD2_Korean_Patch.exe 로 설치하면 됩니다.
  (v1.0.3부터 지원. 안 되면 Steam 설정에서 무결성 확인 후 다시 설치하세요.)

**제거**
- BIOHAZARD2_Korean_Patch.exe 를 실행하고 2(제거)를 고릅니다.
  원본 파일은 게임 폴더의 KoreanPatchBackup 폴더에 보관되어 있다가 제거할 때 제자리로 돌아갑니다.
- Steam의 "게임 파일 무결성 확인"을 하면 패치된 파일이 원본으로 바뀝니다. 그 뒤 다시 쓰려면 설치를 한 번 더 하면 됩니다.

**설치가 "원본과 다름"이라며 멈출 때**
- 게임이 업데이트되었거나 다른 모드가 같은 파일을 바꾼 경우입니다.
  Steam 라이브러리 > BIOHAZARD 2 > 속성 > 설치된 파일 >
  "게임 파일 무결성 확인"을 한 뒤 다시 설치하세요.

**알아 둘 점**
- 런처에 한국어 항목이 추가됩니다. 한국어와 japanese는 모두 한글패치가
  적용된 japanese 폴더의 게임을 실행하며, 같은 세이브를 사용합니다.
- english 등 나머지 언어 항목은 기존과 동일하게 실행됩니다.
- 세이브 파일 이름은 일본어 그대로 저장되므로 패치 전의 세이브도 그대로 이어서 할 수 있습니다.
- japanese 폴더에 version.dll(한글 패치 로더)이 들어갑니다. 같은 이름의
  다른 모드가 있었다면 백업 폴더에 보관됩니다.
